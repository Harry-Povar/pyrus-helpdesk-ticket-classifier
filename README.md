# Pyrus Helpdesk Ticket Classifier

Консольное C#-приложение для автоматической классификации заявок helpdesk в Pyrus с помощью языковой модели в формате ONNX.

Приложение получает задачи из Pyrus, анализирует текст заявки и записывает результаты классификации в соответствующие поля.

## Возможности

- Получает задачи из заданной формы Pyrus.
- Находит задачи с незаполненными полями классификации.
- Объединяет тему и описание заявки и передаёт текст ONNX-модели.
- Определяет отделы для маршрутизации, сервис, тип задачи и приоритет.
- Сопоставляет предсказанные значения с элементами каталогов Pyrus.
- Ищет клиента в каталоге по имени и адресу электронной почты.
- Записывает результаты в незаполненные поля задачи.
- Обрабатывает заявки пакетами и повторно авторизуется в Pyrus при необходимости.

## Компоненты

- Program.cs — взаимодействие с Pyrus API и основной цикл обработки задач.
- TicketClassifier.cs — запуск ONNX-модели и преобразование её выходов в метки классов.
- Tokenizer.cs — токенизация текста для модели XLM-RoBERTa.
- CatalogMapper.cs — сопоставление названий классов с ID элементов каталогов Pyrus.
- ClientFinder.cs — поиск клиента в каталоге.
- ClassificationResult.cs — структура результата классификации.
- LabelsRoot.cs — структура данных с метками классов.
